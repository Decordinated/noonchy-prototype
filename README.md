# noonchy 프로토타입

백엔드 없이 noonchy의 학생, 선생님, 관리자 화면을 모두 눌러 볼 수 있는 HTML 한 장짜리 프로토타입이에요.

- 주소: https://decordinated.github.io/noonchy-prototype/
- 데이터는 보는 사람 브라우저(localStorage)에만 저장돼요. 화면 맨 위 띠의 "처음 상태로 되돌리기"로 초기화할 수 있어요.
- 쇼츠는 실제 유튜브 영상으로 재생돼요. 자막, 조회수 같은 숫자, 정답지 내용은 예시 문장이에요.

## 데모 계정 (비밀번호 `noonchy-dev-1234`)

| 계정 | 역할 |
| --- | --- |
| student@noonchy.local | 학생 |
| teacher@noonchy.local | 선생님 |
| admin@noonchy.local | 관리자 |
| multi@noonchy.local | 학생 + 선생님 |
| norole@noonchy.local | 역할 없음 |

`index.html`은 빌드 결과물이에요. 소스는 프로젝트 공유 폴더의 `prototype/source/`에 있어요.
